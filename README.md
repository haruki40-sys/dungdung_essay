# 이야기 보관함

주인님과 둥둥이·앱둥이가 함께 만든 생각, 이야기, 공부와 실험을 모아두는 개인 콘텐츠 아카이브입니다.

## 주요 콘텐츠

- `essays/`: 주인님 에세이
- `imagination/`: 아이의 상상 이야기
- `gallery/`: 둥둥 미술관
- `english/`: 영어 이야기
- `court/`: AI 재판과 공개 판례

전체 파일 구조와 콘텐츠 현황은 `SITE_MAP.md`를 기준 장부로 사용합니다.

## 관리 원칙

- 기존 콘텐츠와 URL을 우선 보존합니다.
- 새 콘텐츠는 현재 GitHub 최신본을 기준으로 반영합니다.
- 구조 변경 시 링크, 이미지, 음원 및 모바일 메뉴를 함께 확인합니다.
- 기존 AI 재판 저장소와 URL은 통합판 검증 및 이전 안내 완료 전까지 유지합니다.
